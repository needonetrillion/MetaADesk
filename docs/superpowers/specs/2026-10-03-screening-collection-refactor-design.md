# 初筛 / 采集 / 去重重构 设计规格

- 状态：待用户审阅（设计已在对话中逐节确认）
- 日期：2026-10-03
- 项目：Meta 分析初筛系统

## 1. 背景与目标

当前系统把「题录导入 / 删除条目」放在 ③ 初筛，且导入时立即做跨库去重，导致：

1. 初筛页面混入了“采集管理”职责，用户做筛选时还要操心条目增删。
2. 来源库（`search_databases`）是全局共享的，项目之间无法按项目隔离来源库。
3. 去重发生在导入时，无法满足“各数据库原始命中 / 去重后贡献”的 PRISMA 统计口径。
4. 删除检索式 / 来源库缺少级联，会留下孤儿条目。
5. 初筛 AI 的模型与提示词写死、不可见、不可按项目配置，批量处理缺少“跳过已判 / 全部重判 / 暂停续传”。

### 目标

- 把「采集与管理」和「筛选」拆成两层：**② 采集管理，③ 去重 + 筛选**。
- 来源库、排除理由、初筛 AI 模型与提示词均按**项目**隔离。
- 入库**完全不去重**，到 ③ 统一**自动去重合并**，保留最早导入来源的数据。
- 每个来源库给出「原始命中 / 唯一贡献 / 重复剔除」，汇总成 PRISMA 口径。
- 文件（PDF / Markdown）按项目目录组织，可整体删除、备份、查看。

### 成功标准

- 新建项目自动建立专属文件夹；PDF 与 MinerU Markdown 存放在项目文件夹内的文献子目录。
- 导入只落库、标来源，不产生重复标记。
- 进入 ③ 自动展示去重结果；导入 / 删除来源后重算结果一致。
- 删除检索式 / 来源库 / 项目时，条目、判定、全文、提取与文件一并清理，无孤儿数据。
- 初筛 AI 可按项目选模型、查看/编辑提示词、批量处理并显示进度，支持跳过已判与全部重判。

## 4. 现状（关键点）

- `search_databases` 无 `project_id`，全局共享。
- `references` 无 `import_order`；导入时在 `importReferences` 内做跨库/批内去重。
- `deleteStrategy` 只删检索式行，不级联删除文献与批次；来源库无删除接口。
- 文件平铺在 `data/uploads/`、`data/markdown/`，未按项目组织。
- 初筛 AI 提示词硬编码在 `services/ai.ts`；模型通过全局 `screeningProviderId` 选择。
- 设置接口的 `providerSchema` 未接受 `timeoutMs`，导致超时配置保存后丢失。

## 5. 设计

### 5.1 数据模型

- `search_databases` 增加：
  - `project_id TEXT NOT NULL`
  - `preset_key TEXT`（预设：`pubmed/scopus/wos/cnki/wanfang`；自定义为 NULL）
  - 预设库不再启动时全局种入，改为「预设库清单」供项目按需添加。
- `references` 增加：
  - `import_order INTEGER NOT NULL`（全局自增，合并时取最小为主条目）
- `import_batches`：
  - 保留表结构，导入阶段不再计算重复，`duplicate_count` 恒为 0，前端不再显示重复数。
- 新增表 `project_ai_settings`：
  - `project_id`（主键）
  - `assistant_provider_id`（空 = 继承全局默认）
  - `screening_provider_id`（空 = 继承全局筛选/默认）
  - `screening_system_prompt`（文本）
  - `updated_at`
- 新增表 `exclusion_reasons`：
  - `id`、`project_id`、`code`、`label`、`is_builtin`、`sort_order`、`created_at`
  - 新建项目时自动播种一套 PRISMA 默认理由；用户可增删改；始终提供“其他”自由文本。
  - 自定义理由的 `code` 由系统生成（如 `custom_<uuid>`），`label` 由用户填写。
- `screen_decisions` 增加 `reason_note TEXT`：
  - 选「其他」时的补充文字单独存这里，与通用备注 `note` 分开。
- 索引补充：
  - `search_databases(project_id)`
  - `references(import_order)`
  - `references(dedup_group_id)`
  - `references(source_database_id)`
  - `references(source_query_id)`

### 5.2 文件目录

```
data/
  meta.db                          # 结构化数据（集中，逻辑按 project_id 隔离）
  projects/
    <项目ID>/
      project.json                 # 项目名称、创建时间等元数据
      data/
        <文献ID>/
          source.pdf               # 原始 PDF（统一命名）
          markdown.md              # MinerU 转换结果（统一命名）
```

- 新建项目自动建文件夹与 `project.json`。
- PDF / Markdown 用相对路径存储，`data/` 迁移不破坏引用。
- 删除项目删除整个项目文件夹；删除来源库/检索式/单篇只删对应文献文件。

### 5.3 后端服务与接口

- 导入：绑定检索式，只落库、标来源与 `import_order`，不比较重复；返回 `{ imported, total, batchId }`。
- 去重合并服务：按 DOI(小写) → 归一化标题分组；组内按 `import_order` 取主条目，其余标重复；幂等，不碰状态/判定/全文/提取。
- 删除级联：删检索式 / 删来源库 / 删项目均级联删除条目、判定、全文、提取、图表、批次与文件；DB 删除用事务，文件删除在事务外。
- 统计服务：实时计算每库原始命中 / 唯一贡献 / 重复剔除，并汇总 PRISMA 流程数字。
- Agent：上下文只使用当前项目来源库；`preset_key` 匹配检索语法；快速“设计检索策略”只为已添加且无检索式的库生成。
- 设置修复：`providerSchema` 接受并保存 `timeoutMs`。

### 5.4 前端交互

- ② 检索策略：项目来源库列表（原始命中/唯一贡献/重复剔除）、添加来源库（预设/自定义）、展开库显示检索式、导入（粘贴+文件）、条目管理（查看/单删/批量删）、删除库/检索式（确认并显示影响数量）、导入批次撤销。
- ③ 初筛：多列审阅大表；AI「是否可接受 + 理由」两列；人工「判定 + 排除理由 + 备注」列（选「其他」时另有补充说明输入）；来源库列；重复明细；「显示重复条目」开关；顶部合并结果与「重新合并」；移除导入/删除入口。
- ⑤ 提取：提取字段表（手动定义 / 与 AI 讨论生成）；逐篇提取结果以可编辑 Excel 表格展示，人可检查修改；图表数据走内置取点工具（见 5.6）。
- ⑥ 结果：PRISMA 汇总 + 来源库统计表 + 数据结果表 + CSV 导出。

### 5.5 初筛 AI（模型 + 提示词 + 批量）

- 项目级初筛设置：模型选择（继承全局）、提示词查看/编辑。
- 提示词生成方式（Q24）：
  - 一键生成：用「协议（PICO + 纳入/排除标准）+ 本项目检索策略 + 内置方法学常识」生成初稿；
  - 对话迭代：在项目助手里讨论后，把结论保存为初筛提示词；
  - 两种方式生成的提示词都可手工微调。
- 批量处理：使用项目级初筛模型与提示词；显示 `已完成/总数`、`成功/失败`；单块失败不中断。
- 模式：默认「跳过已有 AI 建议」；提供「全部重新判断」；会话内暂停/继续。
- 同意 AI：单条 / 全局 / 勾选三种；只作用于初筛阶段主条目，不回退已推进流程。

### 5.6 数据提取与图表工具（⑤）

- 提取字段表：手动定义 + 与 AI 讨论生成；不同结局是提取表里的不同字段（如死亡率、住院时长各一组字段）。
- 提取结果以数据库存储，界面以**可编辑 Excel 表格**展示，人可直接检查/修改。
- 成对条目模型（长表存储、成对展示）：
  - 字段：`文章ID`、`成对条目ID`、`实验组名称`、`对照组名称`、`实验组均值 + SD/SE`、`对照组均值 + SD/SE`、`目标字段`、`是否纳入展示`、`备注`、`溯源信息`。
  - 一篇文献多处理组时，每个处理组与对照组各占一个成对条目（对照组名称可重复）。
  - 不符合协议的组也存储，但 `是否纳入展示 = false`，不进最终展示/统计。
- 内置图表取点工具：
  - 先标定坐标轴，再逐组点数据点（折线图点曲线、柱状图点柱顶）。
  - 误差线：点均值点 + 点上/下一个端点，差值绝对值记为 SD 或 SE（带类型标记）。
  - 产出 `处理组 × 均值/SD-SE` 表，确认后自动写入对应的 `目标字段`。
  - 保留溯源：原图 + 坐标校准 + 点选结果，可重新定位并复提取。
  - 若实现复杂度过高，回退到“待提取清单 + 外部工具取值 + 人工回填”。

### 5.7 数据流与统计口径

- 采集 → 合并 → 筛选 → 全文 → 提取；删除来源后自动重算合并与统计。
- 每库统计：原始命中 = 该库导入总条数；唯一贡献 = 该库为主条目数；重复剔除 = 差值。
- PRISMA：识别总数 = Σ原始命中；去重剔除 = Σ重复剔除；进入初筛 = Σ唯一贡献。

### 5.8 边界与错误处理

- 合并幂等，只改主/重复标记；主条目被删后次早补位，不继承被删条目判定。
- 文件删除失败不阻断数据库删除，界面提示“部分文件清理失败”。
- 导入解析失败不落库；空文件/无记录明确提示。
- 项目未配置初筛模型/提示词时，继承全局默认 + 内置默认提示词。
- 人工同意 AI 不回退已进入全文/提取的文献。
