# 数据提取重构 设计规格

- 状态：待评审
- 日期：2026-10-09
- 项目：Meta 分析初筛系统

## 1. 目标

把当前「扁平键值」的 ⑤ 数据提取，重构为「两步、两张表」的结构化流程：先穷尽提取原始数据，再按实验组/对照组整理成 meta 分析成对条目；所有 AI 结果可人工编辑；图表数值转交人工。

## 2. 两步流程

### 第 1 步：原始提取（表① 原始数据提取表）

AI 读全文，按「原始数据提取表」模板提取，不做配对、不做 meta 转换。表① 明确分三类：

| 分类 | 内容 | 层级 |
|---|---|---|
| 文献信息 | 标题、第一作者、年份、文献类型、实验地点 | 研究级（一篇一条） |
| 背景信息 | 处理名称、剂量、原料、C/N、温度、时间/茬次、条件 | 组级（每个处理组一条） |
| 结局信息 | 每个目标结局的 n、均值、SD/SE、单位、时间点 | 结局级（每组每个结局一条） |

- 只提取**协议里列出的目标结局**（不提取 pH/EC/温度等非目标指标），外加背景信息。
- 支持**一篇多处理**：背景信息/结局信息按“组 × 时间/茬次”拆多行。
- 农业/多茬文章：提取模板**自动带「时间/茬次」维度**，提示词要求 Agent 按茬次分类，不把多茬混在一起。

### 第 2 步：成对整理（表② 处理组分类表 → 成对表）

- AI 根据协议 I/C + 原始数据，建议「哪些组是实验组、哪些是对照组、怎么配对」，人工确认/修改。
- 按表② 把表① 整理成 **meta 成对表**：实验组 vs 对照组 + 效应量。
- 一个对照组可配多个实验组（多臂）；成对条目加「共享对照组」标记，供后续处理相关性。
- 背景数据作为研究级/组级描述保留，不进成对条目，供亚组/协变量用。

## 3. 图表数值转交人工

- AI 提取时，从图/表读不出的数值标记为「待人工提取」，不猜测。
- 内置图表取点工具（线图/柱状图 + 误差棒：点均值 + 一个端点 = SD/SE）；失败回退外部工具 + 回填。
- 所有 AI 结果均可人工修改。

## 4. 知识分层

1. **内置「数据提取提示词」**（项目级，自动生成 + 可编辑）：当前项目的字段模板 + 判断规则 + 时间/茬次识别。
2. **技能库知识文档**（通用方法论，按需加载）：如《成对条目编码规范》《多茬/多季时间分类》《图表取点规范》。

## 5. 交互设计

- ⑤ 数据提取沿用「左列表 + 右工作区」主从布局（与 ③④ 一致），右侧详情面板 sticky。
- ⑤ 内部两个子视图：
  - **提取工作台**：左 = 全文纳入文献列表；右 = 选中文献的提取工作台，含题录 +「AI 提取」按钮 + 表①（可编辑，分三区）+ 表②（实验组/对照组 + 配对）+ 图表取点。
  - **成对表**：全项目所有成对条目汇总，可编辑、可导出。

## 6. 数据模型（草案）

- `raw_extractions`（表①）：referenceId、level（study/arm/outcome）、字段 JSON（按三类分组）。
- `treatment_classifications`（表②）：referenceId、组名、组类型（experiment/control/other）、配对关系。
- `paired_entries`（成对表）：referenceId、成对条目、实验组/对照组、效应量字段、共享对照组标记。
- 具体字段结构在实现计划中细化。

## 7. 范围与后续

- 本 spec 只覆盖 ⑤ 数据提取重构；不包含初筛 AI 队列式判断（子项目 B）、便携打包（已另有 spec）。
- 效应量计算、亚组/协变量分析、统计合并属后续分析功能，不在本阶段。

## 8. 测试

- 后端：原始提取/成对整理的 service 层测试；图表取点工具测试；数据模型读写。
- 前端无单测框架：typecheck + build + 手工冒烟。
